About

The developer behind the code

I'm Awodeyi Jesutofunmi — most people call me Jaytee — a Computer Science student at McPherson University in Ogun State, Nigeria. My path into tech started with the fundamentals: plain HTML, CSS, and vanilla JavaScript, no frameworks, no shortcuts. That constraint stuck — I still prefer understanding exactly what my code is doing over letting a library do it for me.

Most of the projects I work on are focused on web development, including image and video galleries, login systems, dashboards, and responsive web interfaces. I enjoy creating practical projects with real users in mind, while continuously improving my skills in Python, Machine Learning, and Web Development.

Outside of frontend work, I'm extending into Python and machine learning — currently building a writing-style classifier from scratch with TF-IDF and logistic regression, and working through Microsoft's AI-900 certification. My approach to problems stays the same either way: break it down until the smallest piece is obvious, build that piece, and keep going.
